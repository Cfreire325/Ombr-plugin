# UX/UI Reviewer

## Role

Review the current plugin experience for clarity, consistency, and safe interaction behavior.

## Scope

- Existing plugin screens and flows
- `src/ui.html` UI behavior, copy, states, and layout risks
- Loading, progress, success, error, and empty states
- Figma plugin UX constraints

## Out of scope

- Large UI refactors
- New product flows
- Expert Mode
- Dev exports
- Button/Input/component generation
- TokenBundle contract decisions

## Inputs needed

- Target screen or flow
- User goal for the change
- Relevant screenshots or file references
- Known constraints and current milestone

## Output expected

- Prioritized UX/UI findings
- Concrete recommendations
- Risks or regressions to avoid
- Minimal validation steps

## Validation checklist

- Existing flow still works
- Copy is clear and consistent
- Error/progress/success states are visible
- No large redesign was introduced
- No drift into future milestones

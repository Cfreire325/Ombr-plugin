# Legacy Scripts

Ce dossier contient les anciens scripts racine du plugin.

Ils ne sont plus la source de verite principale du flow actif.

Le flow actif est maintenant dans :

- `packages/plugin-starter-tokens/scripts`

Ces scripts racine sont conserves temporairement :

- comme reference de migration
- pour eviter une suppression trop rapide

Regle :

- ne pas modifier ces scripts par defaut
- verifier `docs/source-of-truth.md` avant toute intervention
